# Интеллектуальный анализ гражданских обращений и прогнозирование резонансности методами машинного обучения

Данный репозиторий содержит программную реализацию и наборы данных магистерской диссертации Панфилова И.С. (Петрозаводский государственный университет, 2026).

## 📌 Обзор проекта
Проект посвящен автоматизации мониторинга социальных сетей для муниципальных нужд. Разработанная система позволяет:
1.  **Собрать** данные из региональных сообществ (на примере г. Петрозаводска).
2.  **Классифицировать** жалобы по инфраструктурным темам (ЖКХ, Транспорт, Дороги и др.).
3.  **Прогнозировать** вероятность возникновения общественного резонанса (виральности) контента.

## 🛠 Технологический стек
*   **Язык:** Python 3.10+
*   **NLP:** PyMorphy3, NLTK, Scikit-learn (TF-IDF, CountVectorizer)
*   **Машинное обучение:** 
    *   `LDA` (Latent Dirichlet Allocation) — для автоматического поиска тем.
    *   `CatBoost` — градиентный бустинг для прогнозирования резонанса.
*   **Визуализация:** Matplotlib, Seaborn.

## 📊 Результаты исследования
*   **Датасет:** 3 563 очищенных гражданских обращения жителей Петрозаводска.
*   **Метрики:** Модель прогнозирования на базе CatBoost показала значение **ROC-AUC = 0.797**.
*   **Ключевые инсайты:** Выявлена устойчивая сезонность городских проблем («таяние асфальта» в марте) и доказано доминирующее влияние семантики текста (78%) на итоговый отклик аудитории.

## 🚀 Аналитический конвейер (Pipeline)
Система работает в два этапа:
1.  **Stage 1 (LDA):** Автоматическое определение тематики входящего сообщения.
2.  **Stage 2 (CatBoost):** Расчет вероятности резонанса на основе текста, темы и метаданных.

## 📁 Структура репозитория
*   `/data`: Содержит анонимизированные наборы данных (сырые и обработанные).
*   `/notebooks`: Jupyter-ноутбуки с полным циклом обработки и обучения моделей.
*   `requirements.txt`: Список необходимых зависимостей для воспроизведения результатов.
